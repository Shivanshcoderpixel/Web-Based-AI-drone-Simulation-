Overview

This project is a web-based AI drone simulation that demonstrates autonomous navigation using Q-Learning (Reinforcement Learning) and the A* Search Algorithm. The drone learns optimal movement strategies while efficiently finding paths and avoiding obstacles in a dynamic environment.

The simulation runs entirely in the browser using JavaScript and provides real-time visualization of the drone's decision-making process.

Features
🧠 Q-Learning Implementation for autonomous learning
📍 A* Search Algorithm for optimal pathfinding
🚧 Obstacle detection and avoidance
🚁 Autonomous drone navigation
⚡ Real-time route optimization
🎮 Interactive web-based simulation
📊 Visualization of learning and pathfinding behavior
